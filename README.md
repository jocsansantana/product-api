# product-api

Mini API para gestionar productos utilizando FastAPI.

## Funcionalidades

- Listar productos
- Crear productos
- Marcar productos como disponibles

## Tecnologías

- Python
- FastAPI
- Uvicorn
- Git
- GitHub

## Ejecución

1. Crear entorno virtual
python -m venv venv

2. Activar entorno virtual
venv\Scripts\Activate

3. Instalar dependencias
pip install -r requirements.txt

4. Ejecutar servidor
uvicorn app.main:app --reload
